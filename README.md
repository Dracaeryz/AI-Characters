# What is this?

Dracaerys' AI character database is an index of all my published character cards for AI based chat programs, such as TavernAI, SillyTavern and Oobabooga Text Generation WebUI.

# What's different about your chat-bots?

For starters, each character profile is designed in the “Spec V2” format for roleplay and chat purposes, using a bio style template. This template is formatted with the proper Australian English or American English definitions, spelling and grammar that the model expects. This allows the more literate models to understand the character better and thus portray them more effectively and faithfully on a consistent basis, even when faced with spelling errors in the user's input.

# What AI software should I use for the best experience?

Each Character has been designed in the “Spec V2” format, which is commonly used in SillyTavern. You can use these cards in other frontends, but you might not get the character's full functionality.

Oobabooga's Text Generation WebUI is also compatable, but certain features like the character's bio data or multiple greetings might be unavailable.

Additionally, they should work correctly in most popular chat programs, like Pygmalion, Character.ai, and TavernAI.

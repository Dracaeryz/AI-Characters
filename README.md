# What is this?

Dracaerys' AI character database is an index of all my published character cards for AI based chat programs, such as TavernAI, SillyTavern and Oobabooga Text Generation WebUI.

# What's different about your chat-bots?

For starters, each character profile is designed in the “Spec V2” format for roleplay and chat purposes, using a bio style template. This template is formatted with the proper Australian English or American English definitions, spelling and grammar that the model expects. This allows the more literate models to understand the character better and thus portray them more effectively and faithfully on a consistent basis, even when faced with spelling errors in the input.

# What AI software should I use for the best experience?

Each Character has been designed in the “Spec V2” format, which is commonly used in SillyTavern. For the best experience, please use that software.

That being said, many of the characters have also been tested in Oobabooga's Text Generation WebUI too, though certain functionalities (such as their bio data) will be unavailable. 

Additionally, they should work correctly in Pygmalion, Character.ai, TavernAI and other popular AI based chat-bot GUIs that use the “V1” character specs.
